# EV0L Commandments of Authority

## Overview

The **EV0L Commandments of Authority** represent the governing command keys within the EV0L matrix. These are not merely moral codes—they are functional protocol keys that control authority operations throughout the BLEU Codex recursive economy. 

The system consists of **Ten visible commandments** (Truth → Legacy) that form the governing pattern, plus **one hidden eleventh commandment** ("It") that serves as the unseen harmonic completing their frequency.

## Proof-of-Authority Gestures

Each activation scene in EVOLVERS - Act I acts as one **proof-of-authority** gesture. These gestures validate commandment activations through:

1. **Executor**: One of the Four (Jetah, Kongo Sonix, Ayana Blue, The Foundation)
2. **Location**: Specific node (BLEUCHAIN node, Codex Altar, etc.)
3. **Elemental Seal**: The seal being invoked (Fire, Water, Air, Earth)
4. **Witnesses**: Other council members or entities observing
5. **Signature Hash**: Cryptographic proof of the gesture
6. **Timestamp**: When the activation occurred

### Example Gesture

```json
{
  "gestureId": "POA-abc123...",
  "commandmentIndex": 4,
  "executedBy": "Jetah",
  "seal": "Fire",

  "timestamp": "2025-11-03T08:00:00Z",
  "witnesses": ["Ayana Blue", "Kongo Sonix"],
  "isValid": true,
  "signatureHash": "a1b2c3d4..."
}
```

## System States

The commandments system can exist in two states:

### 1. Fluid State (Default)
- **Description**: The commandments are "breathing and able to evolve with the next act"
- **Characteristics**: 
  - Can be activated multiple times
  - Proof-of-authority gestures accumulate
  - System responds to new activations
  - Adaptable to narrative evolution

### 2. Sealed State
- **Description**: The Ten are "engraved into the Codex as EV0L Commandments of Authority"
- **Characteristics**:
  - Immutable and permanent
  - No further modifications allowed
  - Historical record locked
  - Final authority established

### Sealing the Commandments

To seal the commandments and engrave them permanently:

```bash
curl -X POST http://localhost:8081/evol/seal
```

This action:
- Sets `SystemState` to "Sealed"
- Records `SealedAt` timestamp
- Makes the commandments immutable
- Establishes them as permanent law within the EV0L matrix
